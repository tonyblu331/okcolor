## `transformCss(input)`

Transforms a CSS string, converting legacy colors to OKLCH — built on Rust/WASM compiled via `wasm-bindgen`.

```ts
import { transformCss } from 'okcolor/core'

const result = transformCss(`
  .card {
    color: #ff0000;
    background: linear-gradient(#f00, #00f);
  }
`)

// .card {
//   color: oklch(62.8% 0.25768 29.23);
//   background: linear-gradient(in oklch, oklch(62.8% 0.25768 29.23), oklch(45.2% 0.31321 264.05));
// }
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `string` | Raw CSS source |

### Returns

`string` — the transformed CSS with all legacy colours replaced by OKLCH.

Gradient colour stops are automatically wrapped in `in oklch` for perceptually uniform interpolation.

## `auditCss(input)`

Scans CSS and reports legacy colour usage without transforming.

```ts
import { auditCss } from 'okcolor/core'

const stats = auditCss(`
  .btn { color: #3b82f6; }
  .alert { border: 1px solid red; }
`)

console.log(stats.legacy_count) // 2
console.log(stats.hex_count)    // 1
console.log(stats.named_count)  // 1
```

### Returns

```ts
interface ScanResult {
  css: string
  legacy_count: number
  hex_count: number
  rgb_count: number
  hsl_count: number
  hwb_count: number
  named_count: number
  gradient_count: number
  unique_count: number
}
```

## Vite Plugin

```ts
import { okColor } from 'okcolor'

// Default options
okColor()

// With options
okColor({
  include: ['src/**/*.css'],
  exclude: ['src/vendor/**'],
})
```

### `OkColorOptions`

```ts
interface OkColorOptions {
  /** Inline comment that prevents conversion on that line. @default 'oklch-ignore' */
  ignoreComment?: string
}
```

## CLI

```bash
# Transform
npx okcolor input.css -o output.css

# Audit
npx okcolor audit input.css

# CI gate
npx okcolor check --max-legacy-colors=10

# Diagnose
npx okcolor doctor
```
