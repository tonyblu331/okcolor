Benchmarks auto-update on each `main` push via GitHub Actions — numbers below reflect the most recent run.

## Cache efficiency

The 4096-slot direct-mapped cache means equivalent colors hit the same slot:

| Input 1 | Input 2 | Same physical color | Cache hit |
|---|---|---|---|
| `#ff0000` | `rgb(255, 0, 0)` | Yes | Yes |
| `#ff0000` | `red` | Yes | Yes |
| `#ff0000` | `hsl(0, 100%, 50%)` | Yes | Yes |
| `#ff000080` | `#ff0000` | No (different alpha) | No |

The cache key packs `(r, g, b, a)` into a single u32. Hash is `key % 4096` via bitmask.

## Why Rust/WASM?

The scanner does not allocate intermediate objects. It walks the input byte-by-byte, dispatching to typed matchers at word boundaries. The gamma decode uses a precomputed 256-entry lookup table. All math is inlined with no function call overhead for hot paths.

The single-pass design means the engine touches each byte exactly once — compare with regex-based approaches that may backtrack or scan multiple times.
