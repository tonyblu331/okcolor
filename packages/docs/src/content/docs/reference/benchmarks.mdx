All benchmarks run on Node.js 26.1.0. The WASM engine (compiled from Rust via `wasm-bindgen`) processes CSS in a single pass and is idempotent — a second pass is a no-op.

## Throughput

| Metric | WASM engine | Old JS engine |
|--------|-------------|---------------|
| **Peak throughput** | **~76 MB/s** (audit) | 11.4 MB/s |
| **Transform throughput** | **~55 MB/s** | 10.1 MB/s |
| **Per-color latency** | **~0.24 µs** (cached) | 1.37 µs |

*Measured on AMD Ryzen 7 5800X. WASM is roughly **5× faster** than the previous pure-JS implementation.*

## Real-world files

| File | Size | Colors | Time | Rate |
|------|------|--------|------|------|
| Small component | 1.3 KB | 8 | **0.024 ms** | 53 MB/s |
| Tailwind-scale | 12 KB | 74 | **0.211 ms** | 55 MB/s |
| Large stylesheet | 100 KB | 592 | **1.73 ms** | 56 MB/s |

## Idempotency

After the first pass every color is already OKLCH. The second pass is a no-op:

| Pass | Colors converted | Time |
|------|------------------|------|
| 1 | 592 | 1.73 ms |
| 2 | 0 | 0.05 ms (scan only) |

## What the WASM engine does per color

1. **Parse** — byte-level scanner with no regex: hex (3/4/6/8), rgb(), hsl(), hwb(), named, `color(srgb …)`
2. **Gamma decode** — sRGB gamma → linear via 256-entry LUT
3. **Matrix multiply** — combined `SRGB → LMS → OKLab` (W3C CSS Color 4 matrices)
4. **Cache lookup** — 4096-slot direct-mapped cache keyed by `(r, g, b, a)` hashes same physical colors across formats
5. **Format** — serialize to `oklch(L% C H)` with CSS Color 4 rounding

Steps 2–5 are cached: `#ff0000`, `rgb(255,0,0)`, `red`, and `hsl(0,100%,50%)` all hit the same cache slot.

## Why Rust?

The scanner does not allocate, avoids regex entirely (char-level parsing), and uses `LazyLock`-initialised gamma lookup tables and named colour maps. The entire crate compiles to ~80 KB WASM with `opt-level="z"` and LTO.

## Compared to alternatives

| Approach | Latency per color | Notes |
|----------|-------------------|-------|
| okcolor (WASM, cached) | **~0.24 µs** | Rust core, Node.js binding |
| okcolor (WASM, cold) | **~0.31 µs** | First occurrence only |
| okcolor (old JS) | ~1.37 µs | Previous pure-JS version |
