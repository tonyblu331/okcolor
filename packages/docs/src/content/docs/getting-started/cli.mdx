## Usage

```bash
npx okcolor input.css -o output.css
```

<TerminalDemo />

## Commands

### `transform`

Transform a single CSS file. This is the default command:

```bash
npx okcolor transform input.css -o output.css
```

### `audit`

Scan CSS files and report legacy color usage:

```bash
npx okcolor audit ./src
```

Output:
```
Found 42 legacy colors:
  - 12 hex values
  - 8 rgb() declarations
  - 15 hsl() declarations
  - 7 named colors
```

### `check`

CI gate. Fails with exit code 1 if legacy colors exceed the limit:

```bash
npx okcolor check --max-legacy-colors=10
```

### `doctor`

Diagnose color issues: malformed values, low contrast, or unexpected patterns:

```bash
npx okcolor doctor ./src
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-o, --output <path>` | Output file path | stdout |
| `--no-gradients` | Skip gradient conversion | gradients enabled |
| `--preserve-comments` | Add `/* was: ... */` comments | false |
| `--format <format>` | Output format (`text`, `json`) | `text` |
| `--max-legacy-colors <n>` | Fail if more than n legacy colors (check) | — |

## Programmatic API

```ts
import { transformCss, auditCss } from 'okcolor/core'

const result = transformCss(`
  .btn { color: #ff0000; }
`)
console.log(result)
// .btn { color: oklch(62.8% 0.25768 29.23); }

const audit = auditCss(source)
console.log(audit.legacy_count) // number of legacy colors found
```
