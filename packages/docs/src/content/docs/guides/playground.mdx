## How it works

okcolor uses a **Rust/WASM engine** that transforms legacy CSS colors into OKLCH at build time. Every conversion follows the **W3C CSS Color Module Level 4** specification, verified against the reference implementation (Culori) with sub-5e-5 error across all sRGB colors.

## The pipeline

Every legacy color goes through 5 stages:

<div class="pipeline-steps">
  <div class="pipeline-step">
    <div class="pipeline-step-num">1</div>
    <div class="pipeline-step-title">Parse</div>
    <div class="pipeline-step-desc">Byte-level scanner identifies hex, rgb(), hsl(), hwb(), named, and color(srgb) values</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">2</div>
    <div class="pipeline-step-title">Gamma decode</div>
    <div class="pipeline-step-desc">sRGB gamma to linear via 256-entry LUT (powf 2.2 / 1/2.4 piecewise)</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">3</div>
    <div class="pipeline-step-title">Matrix multiply</div>
    <div class="pipeline-step-desc">Folded sRGB to LMS to OKLab (Ottosson 2020 matrices per CSS Color 4)</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">4</div>
    <div class="pipeline-step-title">Cache</div>
    <div class="pipeline-step-desc">4096-slot direct-mapped cache: #ff0000, rgb(255,0,0), and red all hit the same slot</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">5</div>
    <div class="pipeline-step-title">Format</div>
    <div class="pipeline-step-desc">Serialize to oklch(L% C H) with CSS Color 4 rounding rules</div>
  </div>
</div>

## Live demo

This example shows CSS being transformed by the WASM engine:

```css
/* Input */
.hero {
  color: #ff0000;
  background: linear-gradient(#00ff00, #0000ff);
}

.btn {
  border: 2px solid hsl(145, 63%, 49%);
  box-shadow: 0 2px 4px rgb(0 0 0 / 20%);
}
```

```css
/* Output */
.hero {
  color: oklch(62.8% 0.25768 29.23);
  background: linear-gradient(in oklch, oklch(86.64% 0.29483 142.5), oklch(45.2% 0.31321 264.05));
}

.btn {
  border: 2px solid oklch(67.72% 0.19 152.54);
  box-shadow: 0 2px 4px oklch(0% 0 0 / 0.2);
}
```

Every converted color is idempotent: running the engine again produces the same output. The WASM engine processes this file in under 0.1 ms.

## What's supported

| Format | Input | Converted? |
|--------|-------|-----------|
| Hex | `#ff0000`, `#f00`, `#ff000080` | Yes |
| RGB / RGBA | `rgb(255,0,0)`, `rgba(255,0,0,0.5)` | Yes |
| HSL / HSLA | `hsl(0,100%,50%)`, `hsla(0,100%,50%,0.5)` | Yes |
| HWB | `hwb(0 0% 0%)`, `hwb(0 0% 0% / 0.5)` | Yes |
| Named | `red`, `rebeccapurple`, `transparent` | Yes |
| `color(srgb)` | `color(srgb 1 0 0)` | Yes |
| Gradients | `linear-gradient(red, blue)` | Yes (injects `in oklch`) |
| OKLCH / OKLab | `oklch(50% 0.2 180)` | No (pass through) |
| `var()` / `calc()` | `var(--color)` | No (pass through) |

Use the escape hatch `/* oklch-ignore */` on any line to skip conversion.
