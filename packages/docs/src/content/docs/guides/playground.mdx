## The conversion pipeline

Every legacy color that passes through okcolor goes through the same 5-stage pipeline:

<div class="pipeline-steps">
  <div class="pipeline-step">
    <div class="pipeline-step-num">1</div>
    <div class="pipeline-step-title">Parse</div>
    <div class="pipeline-step-desc">Character-level scanner with DFA, no regex. Matches hex, rgb, hsl, hwb, named, and color(srgb).</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">2</div>
    <div class="pipeline-step-title">Gamma Decode</div>
    <div class="pipeline-step-desc">sRGB gamma to linear using a 256-entry precomputed LUT (IEC 61966-2-1 piecewise).</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">3</div>
    <div class="pipeline-step-title">OKLab Projection</div>
    <div class="pipeline-step-desc">Folded sRGB to LMS to OKLab matrix multiply. Ottosson 2020 coefficients per CSS Color 4.</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">4</div>
    <div class="pipeline-step-title">Cache Hit</div>
    <div class="pipeline-step-desc">4096-slot direct-mapped cache. Different formats (hex, rgb, named) for the same color all hit the same slot.</div>
  </div>
  <div class="pipeline-step">
    <div class="pipeline-step-num">5</div>
    <div class="pipeline-step-title">Format</div>
    <div class="pipeline-step-desc">Serialize as oklch(L% C H) with CSS Color 4 rounding and powerless-hue clamping.</div>
  </div>
</div>

## Gradient handling

Gradients are special. Without an interpolation hint, browsers interpolate in sRGB space — which produces muddy, desaturated midpoints. okcolor injects `in oklch` into every gradient, ensuring perceptually uniform interpolation:

<TerminalDemo scenario="gradient" />

```css
/* Input */
.card {
  background: linear-gradient(#f00, #00f);
}

/* Output — note the injected interpolation hint */
.card {
  background: linear-gradient(in oklch, oklch(62.8% 0.25768 29.23), oklch(45.2% 0.31321 264.05));
}
```

Already-annotated gradients (`in oklch` or `in oklab`) are left untouched.
